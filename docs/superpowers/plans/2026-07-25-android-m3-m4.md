# Android 基础链路（M3）+ ARCore 轨迹球引导（M4）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 Android App 端到端链路——服务器配置、手动快门拍照、ZIP 上传、状态轮询、GLB 预览、分享导出（M3，不依赖 ARCore 即可用），再加 ARCore 半球轨迹球引导与轨迹点自动拍照（M4）。

**Architecture:** Kotlin + Jetpack Compose 单 Activity + Navigation，MVVM（ViewModel + StateFlow）。纯逻辑（覆盖判定、稳定检测、ZIP、重试、轮询）全部抽成无 Android 依赖的类做 JUnit 单测；网络层经 `ReconService` 接口隔离，测试用 Fake / MockWebServer；Room 用 Robolectric 内存库测。AR/相机/渲染胶水代码只做编译门禁 + 手测。

**Tech Stack:** Kotlin 2.0.21、AGP 8.7.3、Gradle 8.10.2、JDK 17、Compose BOM 2024.12.01、CameraX 1.4.1、Retrofit 2.11 + Gson、OkHttp 4.12、Room 2.6.1（KSP）、DataStore 1.1.1、SceneView 2.3.0（`io.github.sceneview:sceneview` / `:arsceneview`，Maven Central）、Coil 2.7.0、JUnit4 + kotlinx-coroutines-test + MockWebServer + Robolectric 4.13。

## Global Constraints

- Android 代码全部在 `android/` 目录下，包名 `com.recon3d`；目录结构遵循 spec §6：`ui/`、`capture/`、`network/`、`repository/`
- **服务端 API 契约（以 `server/app/main.py` 实际实现为准，不是 spec 原文）：**
  - `POST /api/tasks`：multipart **单文件字段名 `file`**（整个 ZIP），成功 201 → `{"task_id": "a3f9c2"}`；失败 400 → `{"error": {"code": "...", "message_zh": "..."}}`
  - `GET /api/tasks/{id}/status` → `{"task_id", "state", "progress", "stage_detail", "eta_seconds", "error": {"code","message_zh"} | null}`
  - `GET /api/tasks/{id}/model` → GLB 二进制（任务未完成时 409）
  - `GET /api/tasks/{id}/thumbnail` → JPEG（不存在时 404）
  - `DELETE /api/tasks/{id}` → 204
  - state 取值：`uploaded / preprocessing / colmap / training / mesh_export / done / failed`
  - 服务端默认端口 **8000**，局域网 HTTP（App 必须开 `usesCleartextTraffic`）
- 服务端图片下限：上传 ≥ 40 张（App 手动快门"完成"按钮在 ≥40 张解锁）
- M4 轨迹球：3 个俯仰环（20°/45°/70°）× 24 方位角 = 72 目标点；对准判定角度差 < 15°；稳定判定 = 陀螺仪窗口方差低于阈值且持续 0.5s；"完成"解锁 = ≥60 张且覆盖率 ≥ 80%
- 所有逻辑类的异步等待必须可注入（`delayFn` / 时钟参数），单元测试不得真 sleep
- commit 信息用 conventional commits（`feat:`/`test:`/`chore:`）
- 每个 Task 结束跑 `./gradlew :app:testDebugUnitTest`（在 `android/` 目录下），全绿才 commit
- UI/AR 代码的 SceneView API 细节以 2.3.0 编译通过为准；纯逻辑必须严格按计划实现并通过单测

```kotlin
package com.recon3d.network

fun normalizeBaseUrl(input: String): String {
    var s = input.trim().removeSuffix("/")
    require(s.isNotEmpty()) { "服务器地址不能为空" }
    if (!s.startsWith("http://") && !s.startsWith("https://")) s = "http://$s"
    val authority = s.substringAfter("://")
    require(!authority.contains("/")) { "只支持 主机[:端口]，不要填路径" }
    require(authority.isNotBlank()) { "服务器地址不能为空" }
    if (!authority.contains(":")) s = "$s:8000"
    return "$s/"
}
```

```kotlin
package com.recon3d.network

import com.google.gson.annotations.SerializedName
import retrofit2.HttpException

data class CreateTaskResponse(@SerializedName("task_id") val taskId: String)

data class ErrorBody(
    val code: String,
    @SerializedName("message_zh") val messageZh: String,
)

data class TaskStatusDto(
    @SerializedName("task_id") val taskId: String,
    val state: String,
    val progress: Int,
    @SerializedName("stage_detail") val stageDetail: String,
    @SerializedName("eta_seconds") val etaSeconds: Int?,
    val error: ErrorBody?,
)

class ApiException(val code: String, val messageZh: String) : Exception("$code: $messageZh")

private data class ErrorEnvelope(val error: ErrorBody?)

fun HttpException.toApiException(): ApiException {
    val parsed = runCatching {
        com.google.gson.Gson().fromJson(response()?.errorBody()?.string(), ErrorEnvelope::class.java).error
    }.getOrNull()
    return ApiException(
        code = parsed?.code ?: "HTTP_${code()}",
        messageZh = parsed?.messageZh ?: "服务器错误（HTTP ${code()}）",
    )
}
```

`network/NetworkModule.kt`:
```kotlin
package com.recon3d.network

import okhttp3.OkHttpClient
import retrofit2.Retrofit
import retrofit2.converter.gson.GsonConverterFactory
import java.util.concurrent.TimeUnit

object NetworkModule {
    fun buildApi(baseUrl: String): ReconApi {
        val client = OkHttpClient.Builder()
            .connectTimeout(10, TimeUnit.SECONDS)
            .readTimeout(10, TimeUnit.MINUTES)   // GLB 下载可能较慢
            .writeTimeout(10, TimeUnit.MINUTES)  // ZIP 上传可能较慢
            .build()
        return Retrofit.Builder()
            .baseUrl(baseUrl)
            .client(client)
            .addConverterFactory(GsonConverterFactory.create())
            .build()
            .create(ReconApi::class.java)
    }
}
```

```kotlin
package com.recon3d.network

import kotlinx.coroutines.test.runTest
import okhttp3.OkHttpClient
import okhttp3.mockwebserver.MockResponse
import okhttp3.mockwebserver.MockWebServer
import org.junit.After
import org.junit.Assert.assertEquals
import org.junit.Assert.assertNull
import org.junit.Assert.assertTrue
import org.junit.Assert.fail
import org.junit.Before
import org.junit.Test
import retrofit2.HttpException
import retrofit2.Retrofit
import retrofit2.converter.gson.GsonConverterFactory

class ReconApiTest {
    private lateinit var server: MockWebServer
    private lateinit var api: ReconApi

    @Before fun setup() {
        server = MockWebServer()
        server.start()
        api = Retrofit.Builder()
            .baseUrl(server.url("/"))
            .client(OkHttpClient())
            .addConverterFactory(GsonConverterFactory.create())
            .build()
            .create(ReconApi::class.java)
    }

    @After fun tearDown() = server.shutdown()

    @Test fun `status parses all fields including error`() = runTest {
        server.enqueue(MockResponse().setBody(
            """{"task_id":"a3f9c2","state":"failed","progress":30,"stage_detail":"iteration 100/7000","eta_seconds":null,"error":{"code":"COLMAP_LOW_REGISTRATION","message_zh":"位姿配准率过低"}}"""
        ))
        val status = api.getStatus("a3f9c2")
        assertEquals("a3f9c2", status.taskId)
        assertEquals("failed", status.state)
        assertEquals(30, status.progress)
        assertEquals("iteration 100/7000", status.stageDetail)
        assertNull(status.etaSeconds)
        assertEquals("COLMAP_LOW_REGISTRATION", status.error!!.code)
        assertEquals("位姿配准率过低", status.error!!.messageZh)
        assertEquals("/api/tasks/a3f9c2/status", server.takeRequest().path)
    }

    @Test fun `status without error has null error`() = runTest {
        server.enqueue(MockResponse().setBody(
            """{"task_id":"x","state":"training","progress":55,"stage_detail":"","eta_seconds":180,"error":null}"""
        ))
        val status = api.getStatus("x")
        assertEquals("training", status.state)
        assertEquals(180, status.etaSeconds)
        assertNull(status.error)
    }

    @Test fun `400 error body maps to ApiException with code and message_zh`() = runTest {
        server.enqueue(MockResponse().setResponseCode(400).setBody(
            """{"error":{"code":"SERVER_BUSY","message_zh":"服务器忙"}}"""
        ))
        try {
            api.getStatus("x")
            fail("should throw")
        } catch (e: HttpException) {
            val apiEx = e.toApiException()
            assertEquals("SERVER_BUSY", apiEx.code)
            assertEquals("服务器忙", apiEx.messageZh)
```

```kotlin
package com.recon3d.network

import java.io.File
import java.util.zip.ZipEntry
import java.util.zip.ZipOutputStream

object PhotoZipper {
    /** 把 photoDir 内全部 .jpg 平铺打包到 destZip，返回张数。 */
    fun zip(photoDir: File, destZip: File): Int {
        val photos = photoDir.listFiles { f -> f.extension.lowercase() == "jpg" }?.sortedBy { it.name }
            ?: emptyList()
        require(photos.isNotEmpty()) { "没有可上传的照片" }
        destZip.parentFile?.mkdirs()
        ZipOutputStream(destZip.outputStream().buffered()).use { zos ->
            for (photo in photos) {
                zos.putNextEntry(ZipEntry(photo.name))
                photo.inputStream().use { it.copyTo(zos) }
                zos.closeEntry()
            }
        }
        return photos.size
    }
}
```

```kotlin
package com.recon3d.network

import okhttp3.MediaType
import okhttp3.RequestBody
import okio.BufferedSink
import java.io.File

class ProgressRequestBody(
    private val file: File,
    private val mediaType: MediaType?,
    private val onProgress: (Int) -> Unit,
) : RequestBody() {
    override fun contentType(): MediaType? = mediaType

    override fun contentLength(): Long = file.length()

    override fun writeTo(sink: BufferedSink) {
        val total = file.length()
        var written = 0L
        file.inputStream().use { input ->
            val buf = ByteArray(64 * 1024)
            while (true) {
                val n = input.read(buf)
                if (n == -1) break
                sink.write(buf, 0, n)
                written += n
                if (total > 0) onProgress(((written * 100) / total).toInt())
            }
        }
    }
}
```

```kotlin
package com.recon3d.network

import kotlinx.coroutines.currentCoroutineContext
import kotlinx.coroutines.ensureActive
import okhttp3.MediaType
import okhttp3.MultipartBody
import retrofit2.HttpException
import java.io.File

class RetrofitReconService(private val api: ReconApi) : ReconService {

    override suspend fun createTask(zip: File, onProgress: (Int) -> Unit): String {
        val body = ProgressRequestBody(zip, MediaType.parse("application/zip"), onProgress)
        val part = MultipartBody.Part.createFormData("file", zip.name, body)
        try {
            return api.createTask(part).taskId
        } catch (e: HttpException) {
            throw e.toApiException()
        }
    }

    override suspend fun getStatus(taskId: String): TaskStatusDto {
        try {
            return api.getStatus(taskId)
        } catch (e: HttpException) {
            throw e.toApiException()
        }
    }

    override suspend fun downloadModel(taskId: String, dest: File, onProgress: (Int) -> Unit) {
        val body = try {
            api.downloadModel(taskId)
        } catch (e: HttpException) {
            throw e.toApiException()
        }
        dest.parentFile?.mkdirs()
        val total = body.contentLength()
        var copied = 0L
        body.byteStream().use { input ->
            dest.outputStream().use { out ->
                val buf = ByteArray(64 * 1024)
                while (true) {
                    currentCoroutineContext().ensureActive()
                    val n = input.read(buf)
                    if (n == -1) break
                    out.write(buf, 0, n)
                    copied += n
                    if (total > 0) onProgress(((copied * 100) / total).toInt())
                }
            }
        }
    }

    override suspend fun deleteTask(taskId: String) {
        try {
            api.deleteTask(taskId)
        } catch (e: HttpException) {
            throw e.toApiException()
        }
    }
}
```

```kotlin
package com.recon3d.network

import kotlinx.coroutines.delay
import java.io.File
import java.io.IOException

class UploadCoordinator(
    private val service: ReconService,
    private val workDir: File,
    private val maxAttempts: Int = 3,
    private val delayFn: suspend (Long) -> Unit = { delay(it) },
) {
    /** 打包 photoDir 并上传创建任务，返回 taskId。IOException 重试，ApiException 直接抛。 */
    suspend fun upload(photoDir: File, onProgress: (Int) -> Unit = {}): String {
        val zip = File(workDir, "upload_${photoDir.name}.zip")
        PhotoZipper.zip(photoDir, zip)
        var lastError: IOException? = null
        repeat(maxAttempts) { attempt ->
            try {
                return service.createTask(zip, onProgress)
            } catch (e: IOException) {
                lastError = e
                delayFn(1000L * (attempt + 1))
            }
        }
        throw lastError ?: IOException("上传失败")
    }
```

```kotlin
package com.recon3d.repository

import com.recon3d.network.ReconService
import java.io.File

class TaskSync(
    private val service: ReconService,
    private val repo: TaskRepository,
    private val modelsDir: File,
) {
    /** 拉一次状态写库；done 且本地无 GLB 时自动下载。返回最新实体。 */
    suspend fun refreshOnce(taskId: String): TaskEntity? {
        val status = service.getStatus(taskId)
        repo.upsertStatus(status)
        val current = repo.byId(taskId).let { flow ->
            kotlinx.coroutines.flow.first(flow)
        }
        if (status.state == "done" && current?.glbPath == null) {
            val dest = File(modelsDir, "$taskId.glb")
            service.downloadModel(taskId, dest) {}
            repo.markGlb(taskId, dest.absolutePath)
        }
        return kotlinx.coroutines.flow.first(repo.byId(taskId))
    }
}
```

```kotlin
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.flow.stateIn

import java.io.IOException

class HomeViewModel(private val container: AppContainer) : ViewModel() {

    val tasks: StateFlow<List<TaskEntity>> = container.repo.all
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), emptyList())

    private val _serverReachable = MutableStateFlow(true)
    val serverReachable: StateFlow<Boolean> = _serverReachable

    init {
        viewModelScope.launch { pollLoop() }
    }

    private suspend fun pollLoop() {
        while (true) {
            val active = container.repo.all.first().filter { it.isActive() }
            if (active.isEmpty()) {
                _serverReachable.value = container.pingServer()
                delay(5000)
            } else {
                var reachable = true
                for (task in active) {
                    try {
                        container.taskSync.refreshOnce(task.taskId)
                    } catch (e: IOException) {
                        reachable = false
                    } catch (e: ApiException) {
                        if (e.code == "NO_SERVER") reachable = false
                        // HTTP_404：服务端数据已删，本地保留展示
                    }
                }
                _serverReachable.value = reachable
                delay(2000)
            }
        }
    }

    fun deleteTask(task: TaskEntity) {
        viewModelScope.launch {
            runCatching { container.service.deleteTask(task.taskId) }
            task.photoDir?.let { File(it).deleteRecursively() }
            task.glbPath?.let { File(it).delete() }
            container.repo.delete(task.taskId)
        }
```

```kotlin
    data object Idle : UploadUiState
    data class Uploading(val progress: Int) : UploadUiState
    data class Failed(val message: String) : UploadUiState

class CaptureViewModel(private val container: AppContainer) : ViewModel() {

    private val store = SessionPhotoStore(File(container.filesDir, "captures"))

    val sessionDir: File = store.newSession()

    private val _photoCount = MutableStateFlow(0)

            } catch (e: IOException) {
                _uploadState.value = UploadUiState.Failed("上传失败：请检查服务器连接后重试")
            }
        }
```

```kotlin
class TaskDetailViewModel(
    private val container: AppContainer,
    private val taskId: String,
) : ViewModel() {

    val task: StateFlow<TaskEntity?> = container.repo.byId(taskId)
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), null)

    private val _serverUnreachable = MutableStateFlow(false)
    val serverUnreachable: StateFlow<Boolean> = _serverUnreachable

    init {
        viewModelScope.launch { pollLoop() }
    }

    private suspend fun pollLoop() {
        while (true) {
            val current = container.repo.byId(taskId).first() ?: return
            if (!current.isActive()) return
            try {
                container.taskSync.refreshOnce(taskId)
                _serverUnreachable.value = false
            } catch (e: IOException) {
                _serverUnreachable.value = true
            } catch (e: ApiException) {
                if (e.code == "NO_SERVER") _serverUnreachable.value = true
            }
            delay(2000)
        }
    }
```

```kotlin
package com.recon3d.ui.preview

import android.content.ContentValues
import android.content.Context
import android.content.Intent
import android.os.Build
import android.provider.MediaStore
import androidx.core.content.FileProvider
import java.io.File

fun shareGlb(context: Context, glb: File) {
    val uri = FileProvider.getUriForFile(context, "com.recon3d.fileprovider", glb)
    val intent = Intent(Intent.ACTION_SEND).apply {
        type = "model/gltf-binary"
        putExtra(Intent.EXTRA_STREAM, uri)
        addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
    }
    context.startActivity(Intent.createChooser(intent, "分享 GLB"))
}

/** 复制到公共下载目录 Download/3drecon/。API < 29 不支持，返回 false。 */
fun saveGlbToDownloads(context: Context, glb: File): Boolean {
    if (Build.VERSION.SDK_INT < Build.VERSION_CODES.Q) return false
    val values = ContentValues().apply {
        put(MediaStore.Downloads.DISPLAY_NAME, "recon_${glb.name}")
        put(MediaStore.Downloads.MIME_TYPE, "model/gltf-binary")
        put(MediaStore.Downloads.RELATIVE_PATH, "Download/3drecon")
    }
    val resolver = context.contentResolver
    val uri = resolver.insert(MediaStore.Downloads.EXTERNAL_CONTENT_URI, values) ?: return false
    resolver.openOutputStream(uri)?.use { out -> glb.inputStream().use { it.copyTo(out) } }
        ?: return false
    return true
}
```

```kotlin
package com.recon3d.capture

import kotlin.math.acos
import kotlin.math.sqrt

/** 长度 3 的 FloatArray 表示向量。 */
typealias Vec3 = FloatArray

object Vec3Math {
    fun sub(a: Vec3, b: Vec3): Vec3 = floatArrayOf(a[0] - b[0], a[1] - b[1], a[2] - b[2])

    fun dot(a: Vec3, b: Vec3): Float = a[0] * b[0] + a[1] * b[1] + a[2] * b[2]

    fun length(a: Vec3): Float = sqrt(dot(a, a))

    fun normalize(a: Vec3): Vec3 {
        val len = length(a)
        require(len > 1e-6f) { "zero-length vector" }
        return floatArrayOf(a[0] / len, a[1] / len, a[2] / len)
    }

    /** 两向量夹角（度）。零向量抛异常。 */
    fun angleDeg(a: Vec3, b: Vec3): Float {
        val na = normalize(a)
        val nb = normalize(b)
        val cos = dot(na, nb).coerceIn(-1f, 1f)
        return Math.toDegrees(acos(cos).toDouble()).toFloat()
    }
}
```

```kotlin
package com.recon3d.capture

import kotlin.math.cos
import kotlin.math.sin

data class TargetPoint(
    val id: Int,
    val elevationDeg: Float,
    val azimuthDeg: Float,
) {
    /** 从物体中心指向该目标点的单位向量。 */
    val direction: Vec3
        get() {
            val el = Math.toRadians(elevationDeg.toDouble())
            val az = Math.toRadians(azimuthDeg.toDouble())
            return floatArrayOf(
                (cos(el) * cos(az)).toFloat(),
                sin(el).toFloat(),
                (cos(el) * sin(az)).toFloat(),
            )
        }
}

object SphereTargets {
    fun generate(
        elevations: FloatArray = floatArrayOf(20f, 45f, 70f),
        perRing: Int = 24,
    ): List<TargetPoint> {
        val points = mutableListOf<TargetPoint>()
        var id = 0
        for (el in elevations) {
            for (i in 0 until perRing) {
                points.add(TargetPoint(id++, el, i * (360f / perRing)))
            }
        }
        return points
    }
}
```

```kotlin
package com.recon3d.capture

class CoverageTracker(
    private val targets: List<TargetPoint>,
    private val thresholdDeg: Float = 15f,
) {
    private val covered = mutableSetOf<Int>()

    /**
     * 用相机相对锚点的方向更新覆盖。返回本次新覆盖的目标 id 集合。
     * anchorToCamera 无需归一化（内部处理），但必须是"锚点→相机"方向。
     */
    fun update(anchorToCamera: Vec3): Set<Int> {
        val dir = Vec3Math.normalize(anchorToCamera)
        val newly = targets
            .filter { it.id !in covered && Vec3Math.angleDeg(dir, it.direction) <= thresholdDeg }
            .map { it.id }
        covered.addAll(newly)
        return newly.toSet()
    }

    val coveredCount: Int get() = covered.size

    fun coverageRatio(): Float =
        if (targets.isEmpty()) 0f else covered.size.toFloat() / targets.size

    fun isCovered(id: Int): Boolean = id in covered

    fun isFinishUnlocked(
        photoCount: Int,
        minPhotos: Int = 60,
        minCoverage: Float = 0.8f,
    ): Boolean = photoCount >= minPhotos && coverageRatio() >= minCoverage
}
```

```kotlin
package com.recon3d.capture

import kotlin.math.sqrt

/**
 * 陀螺仪稳定检测：最近 windowMs 内角速度模长的方差低于阈值，
 * 且窗口数据已满（最早样本距 now ≥ windowMs），视为"持稳"。
 */
class StabilityDetector(
    private val windowMs: Long = 500,
    private val varianceThreshold: Float = 0.02f,
    private val minSamples: Int = 5,
) {
    private data class Sample(val t: Long, val magnitude: Float)

    private val samples = ArrayDeque<Sample>()

    @Synchronized
    fun onGyro(x: Float, y: Float, z: Float, timestampMs: Long) {
        samples.addLast(Sample(timestampMs, sqrt(x * x + y * y + z * z)))
        val cutoff = timestampMs - windowMs
        while (samples.isNotEmpty() && samples.first().t < cutoff) samples.removeFirst()
    }

    @Synchronized
    fun isStable(nowMs: Long): Boolean {
        if (samples.size < minSamples) return false
        if (nowMs - samples.first().t < windowMs) return false   // 窗口未满
        val mags = samples.map { it.magnitude }
        val mean = mags.average()
        val variance = mags.map { (it - mean) * (it - mean) }.average()
        return variance < varianceThreshold
    }

    @Synchronized
    fun reset() = samples.clear()
}
```

```kotlin
package com.recon3d.capture

import android.graphics.ImageFormat
import android.graphics.Rect
import android.graphics.YuvImage
import android.media.Image
import java.io.ByteArrayOutputStream

object YuvToJpeg {
    /** YUV_420_888 → NV21 → JPEG。调用方负责 close(image)。 */
    fun convert(image: Image, quality: Int = 90): ByteArray {
        val nv21 = yuv420ToNv21(image)
        val yuv = YuvImage(nv21, ImageFormat.NV21, image.width, image.height, null)
        val out = ByteArrayOutputStream()
        yuv.compressToJpeg(Rect(0, 0, image.width, image.height), quality, out)
        return out.toByteArray()
    }

    private fun yuv420ToNv21(image: Image): ByteArray {
        val width = image.width
        val height = image.height
        val ySize = width * height
        val uvSize = width * height / 4
        val nv21 = ByteArray(ySize + uvSize * 2)

        val yPlane = image.planes[0]
        val yBuffer = yPlane.buffer
        val yRowStride = yPlane.rowStride
        var pos = 0
        for (row in 0 until height) {
            yBuffer.position(row * yRowStride)
            yBuffer.get(nv21, pos, width)
            pos += width
        }

        val vPlane = image.planes[2]
        val uPlane = image.planes[1]
        val vBuffer = vPlane.buffer
        val uBuffer = uPlane.buffer
        val vRowStride = vPlane.rowStride
        val uRowStride = uPlane.rowStride
        val vPixelStride = vPlane.pixelStride
        val uPixelStride = uPlane.pixelStride
        val uvWidth = width / 2
        val uvHeight = height / 2
        for (row in 0 until uvHeight) {
            for (col in 0 until uvWidth) {
                nv21[pos++] = vBuffer.get(row * vRowStride + col * vPixelStride)
                nv21[pos++] = uBuffer.get(row * uRowStride + col * uPixelStride)
            }
        }
        return nv21
    }
}
```

```kotlin
    private var anchorPosition: Vec3? = null
    private var lastCaptureMs = 0L
    private var lastGyroMs = 0L   // 传感器时钟（SystemClock 系），与冷却用的 wall clock 分开

    private val _anchored = MutableStateFlow(false)
    val anchored: StateFlow<Boolean> = _anchored

    private val _photoCount = MutableStateFlow(0)
    val photoCount: StateFlow<Int> = _photoCount

    private val _coverage = MutableStateFlow(0f)
    val coverage: StateFlow<Float> = _coverage

    /** 最新一批被覆盖的目标 id（Screen 用来把小球变绿）。 */
    private val _newlyCoveredEvent = MutableStateFlow<Set<Int>>(emptySet())
    val newlyCoveredEvent: StateFlow<Set<Int>> = _newlyCoveredEvent

    private val _uploadState = MutableStateFlow<UploadUiState>(UploadUiState.Idle)
    val uploadState: StateFlow<UploadUiState> = _uploadState

    fun onAnchorSet(anchorPosition: Vec3) {
        this.anchorPosition = anchorPosition
        _anchored.value = true
    }

    fun onGyro(x: Float, y: Float, z: Float, timestampMs: Long) {
        lastGyroMs = timestampMs
        detector.onGyro(x, y, z, timestampMs)
    }

    /**
     * 每帧调用。返回 true 表示应触发一次自动拍照
     * （有新覆盖点 + 持稳 + 冷却已过）。
     * 注意：nowMs 是 wall clock（冷却用）；稳定判定用传感器时钟 lastGyroMs，两者不可混用。
     */
    fun onFrame(cameraPosition: Vec3, nowMs: Long): Boolean {
        val anchor = anchorPosition ?: return false
        val newly = tracker.update(Vec3Math.sub(cameraPosition, anchor))
        if (newly.isNotEmpty()) {
            _newlyCoveredEvent.value = newly
            _coverage.value = tracker.coverageRatio()
        }
        if (newly.isEmpty()) return false
        if (!detector.isStable(lastGyroMs)) return false
        if (nowMs - lastCaptureMs < CAPTURE_COOLDOWN_MS) return false
        lastCaptureMs = nowMs
        return true
    }

    fun onPhotoSaved() {
        _photoCount.value = store.count(sessionDir)
    }

    fun isFinishUnlocked(): Boolean = tracker.isFinishUnlocked(_photoCount.value)

    fun finish(onCreated: (String) -> Unit) {
        if (_uploadState.value is UploadUiState.Uploading) return
        viewModelScope.launch {
            _uploadState.value = UploadUiState.Uploading(0)
            try {
                val taskId = uploadSession(container, sessionDir) { p ->
                    _uploadState.value = UploadUiState.Uploading(p)
                }
                onCreated(taskId)
            } catch (e: ApiException) {
                _uploadState.value = UploadUiState.Failed(e.messageZh)
            } catch (e: IOException) {
                _uploadState.value = UploadUiState.Failed("上传失败：请检查服务器连接后重试")
            }
        }
    }
}
```
